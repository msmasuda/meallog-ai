# MealLog AI — DB自動テストの実行

更新日: 2026-09-03

## 今回の原因と対応

従来、DB関連の5件（DB作成、保存・読出し、日付検索、直近履歴取得、削除）は、Mac上の`flutter test`でスキップされていました。

原因は、Isarがプロジェクト直下などから`libisar.dylib`を探す一方、依存パッケージに含まれるMac用バイナリの場所をテストから指定していなかったことです。Mac用バイナリそのものは、取得済みの`isar_flutter_libs`に含まれていました。

また、以前のテストはDBの初期化エラーを広く握りつぶし、スキップに変換していました。DB作成テストでは検証の失敗までスキップ対象になるため、この処理も削除しました。

## 現在の仕組み

- `test/support/isar_test_support.dart`の`initializeTestIsar()`で、利用中の`isar_flutter_libs`の場所を`.dart_tool/package_config.json`から取得します。特定のユーザー名・キャッシュパス・バージョンをハードコードしません。
- パッケージ内のホスト用バイナリを`Isar.initializeIsarCore(libraries: ..., download: false)`に渡します。
- 読み込み対象はmacOS（Apple Silicon / Intel）、Linux x64、Windows x64です。これ以外の環境は明示的なエラーにします。
- バイナリ不足、バージョン不整合、DB操作エラー、検証結果の不一致をスキップに変換しません。
- 各テスト専用の一時ディレクトリに実際のDBを作成します。テストが失敗した場合も後処理でDBを閉じ、一時データを削除します。
- 初期化するのはMacなどテスト実行ホスト用のDBです。iPhoneに保存済みの献立データは変更しません。

ライブラリの追加ダウンロードやプロジェクト直下への手動コピーは不要です。通常の`flutter pub get`で取得した依存パッケージを使うため、テスト時にダウンロードの競合を避けるための直列化も必要ありません。

## 実行手順

以下のコマンドはプロジェクト直下で実行します。

依存パッケージをまだ取得していない環境では、最初に実行します。

```bash
flutter pub get
```

新規取得した環境やCIでは、`.env.example`を`.env`にコピーしてください。`.env`はアプリに同梱するアセットとして登録されており、テストのビルド時にも必要です。既存の`.env`は上書きしないでください。

DB関連の5件だけを実行する場合:

```bash
flutter test test/core/db/isar_service_test.dart test/features/meal_record/meal_record_repository_test.dart
```

全テストと静的解析:

```bash
flutter test
flutter analyze
```

従来の明示的なビルド設定を併用する場合の検証（通常は不要）:

```bash
flutter test --dart-define-from-file=.env
```

DBテストはエージェントAPIを呼び出しません。`.env`はアセットのビルドに必要ですが、DBの検証内容はその設定値には依存しません。依存関係が取得済みなら、`--no-pub`を追加して依存関係の再解決を省略できます。

## エラーが出た場合

- `isar_flutter_libs`やバイナリが見つからない: `flutter pub get`が正常に完了しているか確認します。
- ホスト環境が未対応: 使用中のOS・CPUに対応するIsarバイナリの提供状況を確認します。スキップして成功扱いにはしません。
- Isarのバージョン不一致: `isar`と`isar_flutter_libs`の依存関係を確認します。
- DB操作や検証が失敗: 通常の不具合として調査し、環境不足という理由で握りつぶさないでください。

## 2026-09-03の検証結果

- 手元のMacでDB関連5件がすべて成功、スキップ0件。
- `.env`設定付きの全テスト24件がすべて成功、スキップ0件。
- 静的解析で問題なし。
- 別の一時テストで意図的に不正な期待値を指定し、スキップではなく検証失敗・終了コード1になることを確認。一時テストは確認後に削除済み。
- アプリ本体のDB処理・モデル定義は変更していません。Linux / Windows上での実行確認は今回行っていません。
